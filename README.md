# NEXUS — Cyborg-Themed Landing Page

A responsive, futuristic landing page concept built for the Techfest IIT Bombay Campus Ambassador Web Development task.

## Features
- Responsive desktop and mobile layouts
- Original CSS-built cyborg illustration (no image asset dependency)
- Animated scanning line, orbit rings and ticker
- Mobile navigation menu
- Pointer parallax interaction on desktop
- Reduced-motion accessibility support
- Semantic sections and accessible labels

## Run locally
Open `index.html` in a browser. For a local server, run:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Publish on GitHub
1. Create a public GitHub repository named `techfest-cyborg-landing-page`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README.
3. Commit the files.
4. Optional: enable GitHub Pages in repository Settings → Pages → Deploy from branch → `main` → `/root`.
5. Use the deployed URL for your live demo if the task accepts it.

## Demo recording checklist (30–60 seconds)
1. Show the landing page from the top.
2. Scroll through Technology, Protocol, Manifesto and Contact sections.
3. Resize to mobile width and show the responsive layout/menu.
4. Move the pointer over the hero artwork to show the parallax effect.
5. Save the recording to Google Drive and set access to “Anyone with the link — Viewer”.

## Submission
The task asks for a GitHub link and a short demo recording through a Google Drive link with viewer access enabled. Put the GitHub repository URL and the demo video in a Google Drive folder (or a short Google Doc containing the GitHub URL plus the video) and submit the shareable Drive link, following the portal's exact instructions.
